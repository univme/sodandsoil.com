# Express Turf Renovation — Project photos

Upload the seven optimized owner-supplied WebP images into this directory on the `feat/owner-project-photography` branch before merging the pull request.

See `docs/owner-photo-integration.md` and the supplied `express-turf-optimized-photos.zip`. Keep the files' exact hyphenated names.

The website uses responsive Next.js Image rendering with descriptive alt text, and temporarily falls back to existing company-hosted images when a pending WebP is absent. Do not deploy the branch to production until all seven photo files are uploaded and verified.
